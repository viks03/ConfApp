Приложението е инсталирано и работи. Тук са нещата, които могат да го
спрат: смяна на домейн, права по папки, настройки в Cloudflare и адресите

## 1. Смяна на домейн

`blockchainedu2026.unwe.bg` е временен. Купен е `icbi.bg` и конференцията
вероятно ще се премести на поддомейн — `conference.icbi.bg` или подобен.

За да не се налага промяна в кода при всяко решение, в `appsettings.json`
може да се зададе шаблон, който покрива всички бъдещи поддомейни:

```
"AllowedHosts": "blockchainedu2026.unwe.bg;icbi.bg;*.icbi.bg;localhost"
```

Това работи и преди сайтът да е преместен — настройката проверява входящите
заявки, а домейн, който още не се ползва, просто не се среща.

⚠️ Ако домейнът не е в този списък, **всяка страница връща 400** и сайтът
изглежда напълно спрян.

### Какво пак трябва да се смени ръчно

Три адреса не могат да се покрият с шаблон:

| Какво             | Къде                                       | Ако се пропусне                          |
| ----------------- | ------------------------------------------ | ---------------------------------------- |
| Адресът в писмата | `appsettings.json` → `AppSettings:BaseUrl` | Кодовете за вход водят към стария домейн |
| Stripe webhook    | Stripe Dashboard → Webhooks                | Платил участник остава непотвърден       |
| Go28 webhook      | панелът на Go28                            | Същото при плащане с криптовалута        |

⚠️ `AppSettings:ForceBaseUrl` определя дали адресът от настройката се ползва
винаги, или само когато заявката не носи собствен. При работа зад Cloudflare
се задава на `1`, за да не се строят връзки от подменен адрес.

## 2. Платежни услуги — webhook адресите

Двете услуги съобщават за плащане на тези адреси:

```
https://<домейн>/api/stripe/webhook
https://<домейн>/api/crypto/webhook
```

**Тези адреси трябва да са достъпни отвън, без никаква проверка пред тях.**

⚠️ Stripe и Go28 са сървъри, не браузъри — те не изпълняват JavaScript.
Всяка защита, която показва проверочна страница, за тях е отказ.

Ако webhook не стигне:

- **Stripe** — плащането с карта остава непотвърдено. Няма друг път.
- **Go28** — приложението проверява поръчката само на всеки 15 секунди, така
  че плащането се хваща със закъснение.

В Stripe Dashboard → Webhooks се вижда дали доставките минават. Отговор
**403** значи, че нещо пред приложението ги спира — почти винаги защитата
в Cloudflare.

До отстраняване плащането може да се потвърди ръчно от админ панела.

## 3. Права за писане

Приложението записва в изброените папки. Ако някоя няма права, съответната
функция спира.

| Папка                                  | За какво                   |
| -------------------------------------- | -------------------------- |
| `App_Data\`                            | базата данни               |
| `DataProtection-Keys\`                 | ключове за сесиите         |
| `logs\`                                | дневник                    |
| `backups\`                             | резервни копия             |
| `wwwroot\uploads\papers26\`            | докладите на участниците   |
| `wwwroot\uploads\submitted-documents\` | документи за верификация   |
| `wwwroot\uploads\people\lecturers\`    | снимки на лектори          |
| `wwwroot\uploads\partners\`            | лога на партньори          |
| `wwwroot\uploads\homepagelogos\`       | лога на началната страница |
| `wwwroot\uploads\program\`             | програмата за сваляне      |
| `wwwroot\uploads\documents\`           | документи за автори        |

Всички пътища са спрямо кореновата папка на приложението — там, където стои
`ConferenceApp.dll`.

Правата се дават на акаунта, под който върви приложението — при IIS това е
`IIS AppPool\<име на pool-а>`.

⚠️ **`DataProtection-Keys` заслужава отделно внимание.** Ако няма права за
писане, приложението не стартира. Това е нарочно: при по-ранна версия то
тръгваше, правеше нов ключ при всяко пускане и **всички влезли излизаха при
всеки рестарт** — без съобщение за грешка никъде. По-добре да не тръгне,
отколкото да работи така.

Ако папката трябва да стои другаде — например на споделен диск — пътят се
задава с променливата на средата `DataProtection__KeysPath`. Празна стойност
значи папката до приложението.

Проверка: файловете в папката не бива да се променят след рестарт.

## 4. Cloudflare

### Настройки, които трябва да са изключени

Всичко, което променя HTML или JavaScript, преди страницата да стигне до
браузъра.

| Настройка                           | Къде                 | Какво причинява                                                                                                                              |
| ----------------------------------- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **Rocket Loader**                   | Speed → Optimization | Променя реда на скриптовете. Мобилното меню спира да се отваря, темата премигва, отброяването застива — без съобщение за грешка в конзолата |
| **Auto Minify**                     | Speed → Optimization | Променя CSS променливите, върху които стъпват темите                                                                                         |
| **Automatic Platform Optimization** | Speed                | Запазва цели страници, включително такива след вход — един участник вижда данните на друг                                                    |
| **Email Obfuscation**               | Scrape Shield        | Спира връзките към имейл адреси                                                                                                              |
| **Mirage**, **Polish**              | Speed → Optimization | Заменят изображенията — логата остават празни                                                                                                |

### Настройки, които трябва да са включени

| Настройка                        | Стойност           |
| -------------------------------- | ------------------ |
| SSL/TLS                          | **Full (strict)**  |
| Proxy status                     | включен за домейна |
| Network → Add visitor IP headers | включено           |

⚠️ Режим `Flexible` води до безкрайно пренасочване
(`ERR_TOO_MANY_REDIRECTS`), защото приложението и Cloudflare се пренасочват
взаимно.

### Страници, които не бива да се запазват

**Rules → Cache Rules**, действие **Bypass cache**, за пътищата:

```
/Admin  /Payment  /Profile  /api  /Login  /Logout
/Register  /Verification  /SubmitDocuments  /Done
```

⚠️ Ако `/Profile` се запазва, **един участник вижда профила на друг**.

### Изключение за платежните услуги

В **WAF** и **Bot Fight Mode** трябва да има изключение (**Skip**) за
`URI Path starts with /api/`.

Режимът „Under Attack" не бива да се включва за целия домейн — той спира и
плащанията.

### Адресът на посетителя

Приложението чете реалния адрес на посетителя от хедъра `CF-Connecting-IP`,
който Cloudflare добавя сам. **Не е нужна настройка от ваша страна**,
стига proxy статусът на домейна да е включен (оранжевото облаче) и
`Network → Add visitor IP headers` да е включено.

Адресът се ползва само за одитния дневник. Заключването при сгрешен вход е
на ниво потребителски акаунт — три неуспешни опита заключват **съответния
акаунт** за 12 часа, не адреса, така че един объркан потребител не блокира
други.

Проверка: админ панел → таб „Одит". Ако всички редове показват един и същ
адрес, proxy-то на Cloudflare е изключено за домейна.

## 5. Тайни

Седем стойности се задават като променливи на средата, не в
`appsettings.json`. Имената са с **две долни черти**, не с двоеточие.

| Променлива                           | За какво                                   |
| ------------------------------------ | ------------------------------------------ |
| `EmailSettings__Password`            | паролата на пощенската кутия               |
| `Stripe__PublishableKey`             | публичен ключ на Stripe                    |
| `Stripe__SecretKey`                  | таен ключ на Stripe                        |
| `Stripe__WebhookSecret`              | проверява подписа на съобщенията от Stripe |
| `Go28__ApiToken`                     | достъп до Go28                             |
| `AdminSettings__SystemAdminPassword` | паролата на администратора                 |
| `RemoteControl__Key`                 | ключ към външната услуга за конфигурация   |

При IIS се задават на ниво application pool.

⚠️ Ако липсват, приложението не се стартира. Това е нарочно — по-добре да не
тръгне, отколкото да работи с празни ключове и плащанията да се провалят
без обяснение.

⚠️ Имената трябва да съвпадат точно. Грешно име не дава грешка — стойността
просто остава празна, а функцията, която зависи от нея, спира да работи.

### По избор

| Променлива                | За какво                                                    |
| ------------------------- | ----------------------------------------------------------- |
| `DataProtection__KeysPath` | друго място за ключовете на сесиите (виж раздел 3)          |

## 6. Проверка след промяна

| Действие                        | Очакван резултат                                          |
| ------------------------------- | --------------------------------------------------------- |
| Отваряне на сайта               | Зарежда се, конзолата на браузъра е чиста                 |
| Заявка за код с истински имейл  | Писмото идва до минута, връзката води към текущия домейн  |
| Вход и отваряне на таб „Одит"   | Последният ред показва вашия адрес, не адреса на проксито |
| Таб „Health"                    | Всичките девет проверки са зелени                         |
| Качване на снимка на лектор     | Качва се и се показва на сайта                            |
| Рестарт на сайта и презареждане | Още сте влезли                                            |

## 7. Чести проблеми

Дневникът е в `logs\conferenceapp-ГГГГ-ММ-ДД.log`.

| Симптом                             | Причина                                                                |
| ----------------------------------- | ---------------------------------------------------------------------- |
| Всяка страница връща 400            | Домейнът липсва в `AllowedHosts`                                       |
| `ERR_TOO_MANY_REDIRECTS`            | SSL/TLS в Cloudflare не е `Full (strict)`                              |
| Приложението не стартира изобщо     | Липсва тайна от раздел 5, или няма права за `DataProtection-Keys`      |
| Менюто не работи, конзолата е чиста | Rocket Loader — изключете и направете Purge Everything                 |
| Платил участник остава непотвърден  | Webhook не стига. Проверете Stripe Dashboard → Webhooks                |
| Не тръгва нито едно писмо           | Таб „Health" → SMTP. Без писма никой не може да влезе — входът е с код |
| Качването на снимки се проваля      | Права за писане в съответната папка от раздел 3                        |
| Всички редове в „Одит" с един адрес | Proxy-то на Cloudflare е изключено за домейна                          |
